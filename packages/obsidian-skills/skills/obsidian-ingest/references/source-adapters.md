# Source adapters

Select one adapter for each selected 00 input; use `mixed` only when the 01 source genuinely compiles more than one kind.

| Adapter | Raw preservation and coverage unit | Boundary |
| --- | --- | --- |
| `document` | Preserve file; cover pages, slides, sections, worksheets, or declared ranges. Render every PDF/PPT/scan page and inventory concrete informative elements and visual regions. A full PDF/slide transcription uses one independent physical-page record plus element units for tables, formulas, charts, flows, screenshots, cases and notes. A transcript-only meeting uses `timestamp-topic-v1` with continuous precise ranges; a companion PDF normally remains a separate input family member. A same-speaker PDF-plus-explanation learning source may combine them only under `pdf-primary-learning-v1`, with separate coverage for every input. | Do not copy OCR noise or layout mechanically; tables, vector charts, screenshots and arrows need complete readable semantic transcription and necessary crop/explicit exclusion. A title, overview, generic page row or generic visual description cannot close an element unit. In learning mode, group the reader body by argument but keep the audit ledger element-level. |
| `image` | Preserve the complete image; cover the full frame and meaningful regions. | State unreadable text or visual ambiguity; never guess. |
| `audio_video` | Preserve media or supplied transcript; cover timestamp ranges. | Keep speaker uncertainty, interruptions, and inaudible ranges. For a requested complete lecture record, clean only noise and same-meaning repetition; preserve the teaching path and move timestamps to the sidecar. |
| `mixed` | List every input separately and cover each in the appendix. For one known speaker and one bounded transcript-plus-slide-photo session, use `slide-photo-primary-learning-v1`, inspect every photo, and align each semantic photo with an exact transcript range or a stated no-verbal-context limitation. | Formats from one event or original remain one evidence family. Do not label every image “现场课件照片”; match visual and spoken meaning before capture order. De-duplicate only genuinely same slides; transcribe text-only slides completely and fold their original image, while diagrams, flows, tables and visual relationships stay visibly embedded immediately before their first precise reader block. |
| `web` | Capture a named public URL as immutable Markdown in its 00 package; use Crawl4AI only for a user-named bounded URL set or explicit research crawl, preserving its manifest, URL, timestamp, and content hash. Save needed screenshot evidence to attachments. | No login, Cookie, paywall bypass, broad site crawl, recommendations, or comment crawl. A bounded corpus never proves whole-site coverage. |
| `social` | Capture the named public post or explicit thread as immutable Markdown in its 00 package. | Do not expand into account history, comments, or related posts unless named. |
| `conversation` | Preserve the selected export or an allowed thread reference and cover turns or bounded sections. | Do not copy credentials, private contacts, or project facts into a general method. |
| `structured_data` | Preserve the file; cover named sheets, tables, ranges, or record sets. | State filters, missing fields, and transformations. |

For a login-gated, deleted, dynamically incomplete, or otherwise inaccessible remote item, save only the permitted failure record, set the source `partial / false`, and stop before 02. “Complete” describes only the declared capture range, never an entire site or platform.
