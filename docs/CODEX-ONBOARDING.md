# Codex onboarding

Give a new Codex this instruction:

> Read this repository's `AGENTS.md`, `00_从这里开始.md`, and the target Vault's `AGENTS.md`. Work only in the repository and the Vault I explicitly name. Start with a read-only inspection and configuration interview; wait for confirmation before creating projects, action cards, or reports. Do not enable automation or workbench writes.

The first session must confirm the user's time zone, work identity, project categories, active projects, default sensitivity, and whether Codex may read user-named task records. Then create only a small demo: three action cards and one Plan → Report → carryover exercise. Do not import historical tasks or remove the Demo without permission.
