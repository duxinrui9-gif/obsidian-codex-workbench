# 从这里开始

这是一个供 Codex 协作维护的手动 Obsidian Vault：它同时支持资料整理、可追溯知识与每日工作闭环。

## 首次使用

1. 用 Obsidian 打开本文件夹，启用 Templates、Daily Notes、Properties 与 Bases。
2. 将 Templates 文件夹设为 `98_Templates`，附件文件夹设为 `99_Attachments`。
3. 把下面的指令发送给负责此 Vault 的 Codex。
4. Codex 先完成配置访谈；用户确认前不创建真实项目、真实任务或知识卡。

> 请读取根目录 `AGENTS.md`、`00_从这里开始.md` 和 `00_知识库配置.md`。只处理当前 Vault 中我明确指定的资料或任务；先检查核心能力并完成配置访谈，在我确认后再创建项目、任务卡、首日演练或知识资产。不要读取 Vault 外目录、聊天历史、账号数据或外部系统；不要启用自动化。

## 两条工作链路

| 目的 | 链路 |
| --- | --- |
| 日常工作 | 任务卡 → Daily Plan → Daily Report → 周报/月报 |
| 知识整理 | 00 原始输入 → 01 完整内容证据 → 02 可复用知识 |

日报只安排和记录任务；知识卡只从完整直接内容来源提炼。索引、摘要和计划都不能替代事实证据。
