# 日报与次日规划

## 输入边界

- 只读取当前 Vault 的任务卡、日报、周/月复盘、用户明确指定的资料与项目页。
- 若用户允许读取其 Codex 任务，只使用指定日期范围内的实际工作结果；任务标题和助手文字不是自动可信事实。
- 不读取外部项目目录、系统日志、聊天数据库或账号资料。

## 早间规划

1. 打开全部未关闭任务：ready、in_progress 与到期 waiting。
2. 选择用户确认的事项写入当天 Daily Plan，并将任务链接写入 action_items。
3. 每项只写目标、具体动作和完成标准；Backlog 与未到期等待项不自动塞入今日计划。

## 晚间日报与收口

1. 建立当天 Daily Report，记录用户提供的实际推进。
2. 区分 [已核验]、[已报告] 与 [待验证]。
3. 对账 Plan 的每个 action_items：完成改为 done，外部输入未到改为 waiting 并设 review_on，继续推进则排到下一个工作日并增加 carryover_count。
4. 不确定、尚未开始或仅有建议的事项保留为 review 或 backlog。

## 周/月复盘

- Weekly Report 只使用同一 ISO 周的 Daily Report。
- Monthly Report 只使用目标自然月的 Daily Report。
- Plan 是执行意图，永远不作为完成、产出或工时事实。

## 失败处理

- 找不到可核验证据时，明确写“无可核验输入”。
- 任务卡缺少下一动作或完成标准时，先补全任务卡，不生成模糊计划。
- 若任务的归属未知，保留“待归类”，不猜测项目。
