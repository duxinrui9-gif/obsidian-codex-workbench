# 周期复盘

## 输入边界

- 只读取目标周期内 `include_in_rollup: true` 的 Daily Report、关联任务卡和用户明确指定的项目页。
- Daily Plan 是执行意图，不作为成果、工时或业务影响证据。
- 未采集的指标保持空白；不要从任务当前状态回推、补零或改写历史报告。

## 周报

1. 只汇总同一 ISO 周内的 Daily Report，先写一屏摘要和项目健康度。
2. 完成事项统计周期内唯一 `done` 关闭任务；结转事件统计日报中实际发生的排期后移。
3. 等待、逾期复查和逾期交付只记录 `metrics_as_of` 收口日快照，不能把每日风险数相加。
4. 依次记录计划与实际、资源与取舍、关键决策、项目详情、下周前三项和停止/降级事项。

## 月报

1. 只汇总目标自然月的 Daily Report；完成和结转遵循与周报相同的聚合规则。
2. 月报依次记录月度结论、目标与结果、项目组合变化、业务影响、资源投入、重复风险、能力资产、继续/调整/停止决策和下月三项押注。
3. 项目变化必须链接可回读的日报、任务或项目证据；没有核验输入时明确标记缺口。

## 收口检查

- 指标写入后不随任务后续变化重算。
- 报告只描述已经发生的事实、明确判断和待验证项；不要把建议或规划写成完成。
- 仍有等待、逾期或证据缺口时，在风险区明确保留，不以叙事方式掩盖。
